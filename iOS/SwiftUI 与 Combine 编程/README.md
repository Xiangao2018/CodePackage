# SwiftUI 与 Combine 编程

## 第一章 

### 指令式（imperative）编程与声明式（declarative）编程

**指令式编程**：教计算机一步步怎么做，下发一条条指令；利于机器的执行；
**声明式编程**：结果导向的，通过函数编程来实现；这样更利于人进行阅读；


### 声明式UI

特点：

+ 代表 UI 层的 View，并不是真实负责渲染的实图，仅仅是一个**虚拟**对 View 组织关系的描述;
+ 决定 UI 用户状态 State 被存储在某个或某几个对象中;
+ 用一个函数描述 View，这个函数的输入参数是 State，即 View = f(State);
+ 框架在 State 改变时，调用上述函数获取对应新的 State 的 View，并与当前的 View 进行差分计算，并重新渲染更改的部分.


### 练习

1. 区分指令式和声明式
下列语句分别是哪种思想的体现？是指令式还是声明式？
    a. 去超市买一只鸡，然后用微波炉 600W 加热三分钟以后装盘。  --- 指令式  ---  得到一盘经过微波炉 600W 加热三分钟的熟鸡。
    b. 将文件夹中尺寸大于 1MB 的文件按修改日期排序并打印它们的文件名。 --- 指令式  ---  输出文件夹中所有大于 1MB 的文件名，并按修改日期排序。
    c. 画一组圆心在 (0, 0)，半径以 5 逐渐增加的圆。 --- 声明式 
    d. 将画笔移动到 (0, 0)，从 (0, 0) 到 (1, 1) 画一条线。 --- 指令式  ---  得到一条从 (0,0) 到 (1,1) 的直线。



## 第二章

### Modifier 分类

+ 像是 font，foregroundColor 这样定义在具体类型 (比如例中的 Text) 上，然后
返回同样类型 (Text) 的原地 modifier。
+ 像是 padding，background 这样定义在 View extension 中，将原来的 View
进行包装并返回新的 View 的封装类 modifier。
