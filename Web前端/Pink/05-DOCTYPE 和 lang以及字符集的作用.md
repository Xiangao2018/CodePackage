# DOCTYPE 和 lang以及字符集的作用

## DOCTYPE

+ <!DOCTYPE> 声明位于文档中的最前面的位置，处于 <html>标签之前
+ <!DOCTYPE> 不是一个 HTML 标签，它是文档类型声明的标签。

## lang

<html lang="en"> </html>

当前文档显示的语言


## 字符集的作用

告诉当前网页应该使用哪种字符编码

<html lang="en">
    <head> 
    <meta charset="UTF-8">
    </head>
</html>
